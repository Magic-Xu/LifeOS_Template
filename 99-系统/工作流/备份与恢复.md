# 备份与恢复

## 生成备份

```bash
./脚本/生成加密备份.sh
```

生成前可运行：

```bash
./脚本/检查知识库质量.sh
```

质量检查在加密备份达到 80 MiB 时提前预警；现有 95 MiB 提交保护仍是硬停止线。预警出现后先决定新的备份存储方式，不自动分卷或迁移。

## 验证备份

```bash
./脚本/验证备份.sh "LifeOS-日期.zip.age" "/仓库外/人生库解密密钥.txt"
```

## 恢复备份

```bash
./脚本/恢复加密备份.sh "LifeOS-日期.zip.age" "/仓库外/人生库解密密钥.txt" "/新的恢复目录"
```

恢复必须写入新目录，验证无误后再决定是否替换工作库。
