# 上下文读取路由

按任务选择最小范围，不默认读取所有目录。

| 用户问题 | 首先读取 | 按需补充 |
|---|---|---|
| 我的身份、背景或长期偏好 | `99-系统/AI上下文/我的概况.md` | `重要偏好与边界.md`、对应权威经历 |
| 我最近应该优先做什么 | `99-系统/AI上下文/当前目标.md` | `10-人生经历/目标与复盘`、最近 14 天日记 |
| 某件事何时发生或回顾人生时间线 | `10-人生经历/经历索引.md` | 对应事件、决定或当时日记 |
| 结合过去经历帮我决策 | `10-人生经历/决定与结果` | 相关事件、相关人物、当时日记 |
| 工作、职业发展或职场风险 | `10-人生经历/职业经历` 中的职业总览或最近事件 | `99-系统/AI上下文/当前目标.md`、其他相关职业记录 |
| 项目或技术选择为什么这样决定 | `10-人生经历/决定与结果` | 相关项目记录、当时目标和后续结果 |
| 我现在情绪不好 | `99-系统/AI上下文/重要偏好与边界.md` | 最近日记、过去有效的应对记录 |
| 某个人或人脉问题 | `20-人物关系` 中对应人物 | 共同事件、最近互动日记 |
| 健康问题 | `30-健康/健康总览.md` | 症状、检查、用药及相关原始报告 |
| 护肤进度或产品调整 | `50-兴趣与生活/外貌与护肤` 中的当前方案 | `99-系统/AI上下文/当前目标.md`、`30-健康/健康总览.md` |
| 财务问题 | `40-财务/财务总览.md` | 指定月份的交易、预算和资产负债记录 |
| 读书、电影或兴趣 | `50-兴趣与生活` 中对应子目录 | 相关日记和历史评价 |
| 旅行计划或回忆 | `50-兴趣与生活/旅行` | 地点、同行人物、照片和相关日记 |
| 哪些信息待确认或互相冲突 | `99-系统/AI上下文/待确认与冲突.md` | 对应权威记录和来源 |
| LifeOS 是否健康、是否该备份或清理 | `99-系统/AI上下文/系统状态.md` | 运行 `脚本/检查知识库质量.sh` 获取实时结果 |
| 整理新资料 | `00-收件箱` | 与资料有关的目标目录和总览 |

读取规则：

1. 先读总览或索引，再读原始记录。
2. 以日期、来源和记录 ID 判断可靠性。
3. 文件缺失时继续使用已有材料，但明确说明缺口。
4. 不把“没有找到记录”解释为“没有发生过”。
5. 文件名未命中时检查权威页面的 `别名`；别名仍未命中再拆分问题关键词，不直接全库无差别读取。
