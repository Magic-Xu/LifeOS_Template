# 上下文读取路由

按任务选择最小范围，不默认读取所有目录。

| 用户问题 | 首先读取 | 按需补充 |
|---|---|---|
| 我最近应该优先做什么 | `99-系统/AI上下文/当前目标.md` | `10-人生经历/目标与复盘`、最近 14 天日记 |
| 结合过去经历帮我决策 | `10-人生经历/决定与结果` | 相关事件、相关人物、当时日记 |
| 我现在情绪不好 | `99-系统/AI上下文/重要偏好与边界.md` | 最近日记、过去有效的应对记录 |
| 某个人或人脉问题 | `20-人物关系` 中对应人物 | 共同事件、最近互动日记 |
| 健康问题 | `30-健康/健康总览.md` | 症状、检查、用药及相关原始报告 |
| 财务问题 | `40-财务/财务总览.md` | 指定月份的交易、预算和资产负债记录 |
| 读书、电影或兴趣 | `50-兴趣与生活` 中对应子目录 | 相关日记和历史评价 |
| 旅行计划或回忆 | `50-兴趣与生活/旅行` | 地点、同行人物、照片和相关日记 |
| 整理新资料 | `00-收件箱` | 与资料有关的目标目录和总览 |

读取规则：

1. 先读总览或索引，再读原始记录。
2. 以日期、来源和记录 ID 判断可靠性。
3. 文件缺失时继续使用已有材料，但明确说明缺口。
4. 不把“没有找到记录”解释为“没有发生过”。
