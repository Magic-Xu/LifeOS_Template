# 收件箱归档规则

## 归档步骤

1. 列出待整理文件及格式。
2. 判断每份材料的主要对象、时间和领域。
3. 判断保存级别：默认精简归纳；只有用户明确要求时才完整保留。
4. 输出计划，不立即移动。计划必须写明保存级别及源文件处理方式。
5. 用户确认后执行移动、重命名、建卡和链接。
6. 默认精简材料的源文件移入 `.trash/待清理-YYYY-MM-DD/`，到期日为整理日后 30 天。
7. 生成整理报告并检查 Git 状态。

## 原文保存级别

### 默认：精简归纳

- 提取对未来判断有用的事实、感受、解释、目标和不确定性。
- 不在长期知识目录保存收件箱原文。
- 来源写成“用户自述或材料导入于 YYYY-MM-DD；原文未长期保存”，不创建失效链接。
- 源文件进入 `.trash`，不进入 Git 或加密备份；到期后列入永久清理计划。

### 用户明确要求：完整保留

- 只有用户明确说“完整保留”“保存原文”或同义表达时执行。
- 原文原样移动到权威位置，不改写；结构化记录通过链接引用。

### AI 提醒完整保留

- AI 不得自行提高保存级别。
- 仅对不可替代的个人书信与回忆、原始照片或音视频、关键医疗或法律证据、重大人生转折材料提醒一次。
- 提醒必须说明不可替代之处；用户未确认时仍按精简归纳处理。
- 用户直接写入 `01-日记` 或长期资料目录的内容视为主动保存，不适用本节的收件箱默认规则。

## 目标目录

- 个人经历、重要决定、目标复盘：`10-人生经历`
- 人物资料、互动和关系：`20-人物关系`
- 病史、症状、检查、用药、生活指标：`30-健康`
- 收入、支出、资产负债、预算：`40-财务`
- 阅读、电影、旅行、爱好、外貌护肤：`50-兴趣与生活`
- 图片、音频、视频、PDF 等附件：`90-附件`

## 冲突与重复

- 完整保留的跨领域材料选择一个权威原文位置，其他位置使用链接。
- 默认精简的跨领域材料把不同事实写入各自权威记录，并使用同一来源日期和来源类型。
- 新资料与旧资料冲突时保留双方，并标记冲突，不能静默覆盖。
- 人物评价和心理判断必须标记为主观感受或 AI 推断。
- 已明确完整保留的原始账单、报告、照片和日记不可因已抽取信息而删除。

## 整理报告

报告至少包含：处理文件、保存级别、移动位置或 `.trash` 到期日、新建记录、更新链接、发现的冲突、需要用户决定的问题。
